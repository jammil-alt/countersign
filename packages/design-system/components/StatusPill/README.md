# StatusPill

Rounded status label in four tones, always a word.

- Consumer provides: `span.ds-pill.ds-pill--{neutral|accent|positive|warning}` with a one- or two-word label in sentence case.
- neutral: draft, not started. accent (slate): the team is on it. positive: signed, paid, done. warning (signal gold): waiting on you, or a price change.
- For errors use `Banner` (risk), not a pill.
