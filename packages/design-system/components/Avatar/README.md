# Avatar

Round initials, never photos.

- Consumer provides: `span.ds-avatar` (32px; `--lg` 44, `--sm` 28) with initials.
- The Mezonas lead is always `mz-lead` (copper-ink on copper-tint). Team roles use slate or ink-muted fills; the signed-in client is `ds-avatar--self` (ink). Empty seats are `ds-avatar--empty` (dashed).
- Stacks: wrap in `ds-avatars`; overflow shows as `+N` in self style.
