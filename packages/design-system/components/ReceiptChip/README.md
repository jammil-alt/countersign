# ReceiptChip

Links a result to its Receipt: the document, email or record behind it.

- Consumer provides: `button.mz-receipt` with a 14px icon (`mz-receipt`, `mz-email`, `mz-document`) and a short reference in `reference` text ("INV-2291", "Aging report · p. 2").
- Every number a client sees should have one nearby. Opens the source.
