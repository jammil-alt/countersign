# ListRow

A clickable row inside a card: title, meta line, trailing status.

- Consumer provides: `button.ds-listrow` with `ds-listrow__title`, `ds-listrow__meta` (count and who's on it) and an optional trailing `StatusPill`.
- 52px minimum (`row-h-comfortable`); hover is `surface-subtle`. For multi-column data use a table pattern.
