# PersonChip

A person or team role with their name and role.

- Consumer provides: `span.mz-person` with an Avatar and the name plus a `small` role line. The lead uses `mz-person--lead` (copper) and an `mz-lead` avatar; team roles use `mz-person--role` and a one-letter avatar.
- Copper always means a person; agents' work stays in ink.
