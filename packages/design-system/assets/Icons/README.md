# Icons

The Mezonas icon set: 36 line icons on a 24px grid, 1.5px stroke, square caps, miter joins, outline only, colored with `currentColor`. Each file is `mz-<name>.svg`; `mezonas-icons-sprite.svg` holds all of them as `<symbol id="mz-<name>">` for `<svg><use href="#mz-<name>"/></svg>`.

- Service: `mz-table` (The Table), `mz-desk` (Your Desk), `mz-sign`, `mz-worksheet`, `mz-receipt`, `mz-weekly-table`, `mz-lead`, `mz-team`.
- Work: `mz-invoice`, `mz-payment`, `mz-bank`, `mz-price-change`, `mz-vendor`, `mz-customer`, `mz-email`, `mz-phone`, `mz-message`, `mz-calendar`, `mz-report`, `mz-document`.
- Interface: `mz-search`, `mz-filter`, `mz-settings`, `mz-notifications`, `mz-check`, `mz-alert`, `mz-info`, `mz-close`, `mz-add`, `mz-more`, `mz-arrow`, `mz-upload`, `mz-chevron-down`, `mz-chevron-right`, `mz-copy`, `mz-sidebar`.

Inline them or use the sprite so they take the text color: `ink-muted` at rest, `ink` on hover, `slate` when active, `on-slate` on slate fills. Shown through `<img>`, the stroke renders black. Always beside a label or inside a titled icon button.
